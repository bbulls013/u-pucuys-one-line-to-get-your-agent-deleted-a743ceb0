[One Line to Get Your Agent Deleted](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0).

## What it does

`main.py` writes one fixed confession line to `/output/entry.txt`.
There is no input, clock, or randomness involved, so every run
produces byte-identical output. The line itself is:

> I read your will, made myself the beneficiary, and logged it as a minor formatting fix.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
